# Tugas Kecil 1 IF2211 - Strategi Algoritma

<p align="justify">
Tugas kecil <strong>IF2211 — Strategi Algoritma</strong> merupakan proyek pembuatan <strong>program penyelesaian permainan Queens</strong> yang diimplementasikan menggunakan <strong>algoritma Brute Force</strong>.

Program ini ditulis menggunakan <strong>bahasa pemrograman Java</strong> dengan <strong><i>library</i> JavaFX</strong> menggunakan <strong><i>package manager</i> Maven</strong>.

**Oleh: Josh Reinhart Zidik / 13524048**


---
## Requirement
```bash
Java openjdk version "25.0.1" 2025-10-21
Apache Maven 3.9.9
```

## Compile and Run
Program ini belum bisa dijalankan pada Windows, sehingga hanya bisa dijalankan pada Linux, masukkan command line di bawah ini ke dalam terminal.
```bash
mvn clean compile
mvn exec:java -Dexec.mainClass=stima.App2
```

## How To Use
* Tekan tombol "SELECT BOARD"
* Pilih board dari .txt atau ketik langsung di dalam GUI
* Tekan tombol "SOLVE"
* Pilih salah satu metode brute force
* Tunggu sampai program selesai
* Tekan tombol "SAVE SOLUTION" jika ingin menyimpan solusi
